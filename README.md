# Солнечная долина — браузерный прототип

Открыть `index.html` в любом браузере (двойной щелчок). Работает офлайн, без установки.

Управление: ← → / A D — бег; Пробел / ↑ / W — прыжок (держать — выше); P или Esc — пауза; M — звук; R — заново.
На телефоне/планшете появляются экранные кнопки ◀ ▶ и прыжок.

Правила: без смертей и штрафов. Колючки, ямы и улитки возвращают на последний цветок-чекпоинт.
Улитку можно «перепрыгнуть сверху». Звёзды 1–3 по числу собранных солнышек. Рекорд — в localStorage браузера.

Игра полностью отделена от приложения ЯмогУ!: не читает и не меняет задания, монеты, Room.

Тесты (Edge, без окна): `powershell -NoProfile -File run_selftest.ps1` — бот проходит уровень; результат в строке SELFTEST.
Снимки: `index.html?shot=600` (бот играет 600 кадров и показывает кадр).
Графика временная (фигуры). Звук — синтезированные тона.
